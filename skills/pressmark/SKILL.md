# Pressmark

Author: Daniel Hallman

Vector document synthesis engine for generating PDF invoices, estimates, receipts, contracts, NDAs, and real estate agreements with optional QR code payment links.

## Quick start

1. Open [Pressmark Studio](https://pressmark.dev) to use the interactive web studio, browse templates, or connect your MCP agent to `https://pressmark.dev/mcp`.
2. Connect any Streamable HTTP MCP client to `https://pressmark.dev/mcp` (no credentials required for guest compilation) to call `generate_document`, `preview_document`, `calculate_totals`, `get_pricing`, `convert_document`, and `record_payment`.
